# Charter

## Purpose

Techne is a retained source and held-work repository for the Knowledge Islands ecosystem.

Arcadia now defines the canonical engineering practice for AI-native systems, including architecture, execution, operating models, governance, tooling evaluation, and Knowledge Islands implementation patterns.

## Scope

The base preserves noncanonical engineering snapshots, source evidence, governance history, existing held change proposals, time-bound records and external references relevant to Techne. It is no longer an active principal or canonical engineering knowledge owner.
