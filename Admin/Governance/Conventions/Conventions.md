# Conventions

Conventions collects the Techne-specific rules that supplement the portable Knowledge Islands standards declared in `.ki-config.toml`.

## Language and authoring

- Write base notes in British English.
- Keep each paragraph on one source line, separated by a blank line.
- Use the `ki-authoring` standard for Markdown and TOML details.
- Keep engineering claims in Techne within the authority boundary defined by [[Charter]] and [[Known Lands]].

## Links and navigation

- Use shortest-unique Obsidian wikilinks between notes in the Knowledge Base.
- Use relative Markdown links only in repository-orientation files outside the zone model.
- Add a same-name index note when a canonical subfolder needs a durable navigation entry point.

## Knowledge placement

- `Admin/` holds Techne's governance and operating model.
- [[Engineering Practice]] holds settled internal engineering discipline.
- [[Resources]] holds knowledge from independently existing external sources.
- [[Streams]] holds proposals and other work in motion.
- [[Calendar]] holds time-bound records; `+/` and `-/` remain staging areas.

## Change governance

Substantive changes to `Admin/`, `Pillars/`, or `Resources/` proceed through an approved Stream proposal under [[Enactment Process]]. Trivial corrections, time-bound Calendar entries, and inbound `+/` triage remain lightweight exceptions.

Before authoring canonical knowledge in an active Pillar, load that Pillar's `MEMORY.md` as well as [[Admin/MEMORY|Memory]].
